# Metro Rush

A subway-style endless runner built with HTML, CSS, and JavaScript.

## Play

Open `index.html` locally, or enable GitHub Pages:

1. Open [Settings → Pages](https://github.com/moeid1804/Demo/settings/pages).
2. Choose **Deploy from a branch**.
3. Choose **main**, **/ (root)**, and **Save**.
4. Wait for deployment, then click **Visit site**.

The expected game URL is https://moeid1804.github.io/Demo/ once Pages is enabled and deployment succeeds.

## Controls

- Arrow keys or WASD: switch lanes, jump, and slide.
- P or Escape: pause/resume.
- Mobile: swipe or use the on-screen buttons.

Collect coins, jump striped barriers, slide under yellow gates, and avoid trains. Best distance is saved in your browser.

No build step or dependencies required.
